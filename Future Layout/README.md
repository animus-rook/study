# secplus-detection-notes

Personal cybersecurity learning vault — synced with Obsidian. Documenting my
journey from Technology Service Technician toward Detection Engineer, covering
CompTIA Security+ (SY0-701), CompTIA CySA+ (CS0-004), Blue Team Level 1
(BTL1), and detection-as-code work.
