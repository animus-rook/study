# 02 — Threats, Vulnerabilities, Mitigations

Security+ Domain 2 (22%, the largest single domain most candidates underestimate).

## Objectives Checklist
- [ ] Threat actor types and motivations
- [ ] Malware types: ransomware, worms, trojans, rootkits, fileless, botnets
- [ ] Social engineering: phishing variants, pretexting, BEC, deepfakes
- [ ] Physical/network attacks: on-path, DoS/DDoS, DNS attacks, wireless attacks
- [ ] Vulnerability types: application, OS, web-based, cloud-specific, zero-day
- [ ] CVE/CVSS scoring
- [ ] Mitigation techniques: segmentation, patching, hardening, compensating controls

First lab debrief for this folder: run a vulnerability scan (Nmap + OpenVAS/
Nessus Essentials) against a lab VM — use `_templates/lab-debrief.md`.
