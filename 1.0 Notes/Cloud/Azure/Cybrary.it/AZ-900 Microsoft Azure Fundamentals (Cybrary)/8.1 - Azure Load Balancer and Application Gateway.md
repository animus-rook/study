## What is a Load Balancer?
- device that distributes traffic between systems in a pool or cluster 
- Round Robin
- Switches traffic
- Can have multiple servers behind load balancer 
- Load balancer can be private (Virtual Private Network)or public
	- Services 
		- Azure Load balancer 
			- Fully managed
			- Balance TCP or UDP
			- Inbound and outbound scenarios
			- Low lAtency and high throughput
			- Configuration only
		- Azure Application Gateway
			- Web Traffic only
			- Web applications firewall (AWF)
			- SSL Termination
			- URL-based routes and HTTP headers rewrite
			- Session affinity
