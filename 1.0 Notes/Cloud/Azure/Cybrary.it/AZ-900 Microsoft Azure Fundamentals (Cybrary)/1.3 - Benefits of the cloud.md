- Cost Effective
	- Pay as you go/consumption model
	- No upfront costs
	- Stop paying for resources you don't need
	- Better cost prediction
- Scalable
	- "unlimited resources"
		- Vertical Scaling (scale up) More CPU or RAM
		- Horizontal Scaling (scale out) new server with same capacity as previous
	- Manual or automated
- Elastic
	- increase/decrease on demand
	- Accommodate unexpected spikes
	- Reduce consumption during low use
- Up to Date
	- Latest Hardware
	- Latest Software
	- Lower IT maintenance cost
- Reliable
	- redundant data centers
	- redundant (fault-tolerant) services
	- Data backups and replication
	- Disaster recovery
- Global 
	- data centers around the globe
	- closer to customers
	- meet data-residency and compliance laws
- Secure
	- Physical Security
	- established policies and controls
	- experienced Personnel
	- Shared security model (both partied have security responsibilities)
Economies of Scale
- Efficiency
- Lower-cost per unit
- tax and utility savings
