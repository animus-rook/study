NIST [[Definition of Cloud Computing]]

High lights
- Fundamental computing resources
- Deploy and run arbitrary software
- does not manage or control the underlying cloud infrastructure
==What are the fundamental resources you can rent?==

- Compute
	- Virtual Machines
		- Hyper visor
	- Containers
		- Container Engine no hypervisor
	- Serverless
		- Serverless runtime
			- Serverless function (only paid for while running)
- Storage
	- Virtual Disk
	- File Share
	- Relational Database
	- Document Database 
	- Blob service
	- Key/value (table) storage
	- Queue Storage
- Networking
	- Virtual Network
	- Global Traffic Manager
	- DNS
	- Firewalls
	- Load Balancers
