Capital expenditures (CapEx) (initial investment)
- CapEx is an upfront cost with value that reduces over time 
	- Examples
		- Server costs
		- Storage Costs
		- Network Costs
		- Backup and archival costs
		- Business and continuity and disaster recovery
		- technical personnel
		- Data infrastructure cost
	- Benefits
		- Fixed Cost 
		- Budget Friendly
		- Easy for planning
Operational Expenditures (OpEx) (on going cost)
- OpEx is an expense that you incur every month in which you consume services or products
	- Examples
		- Leasing Cloud Software
		- Leasing cloud infrastructure
		- Charges for scaling resources 
		- Per user billing
