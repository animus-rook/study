### Cloud Computing
> Using computers and other infrastructure running applications accessible over the internet

Provides financial benefit as you pay for what you need. 
### Shared Responsibility model
- Moving to cloud means that responsibility is shared with cloud provider 
	- Responsibility for any cloud deployment is always shared between user and provider
![[shared-responsibility.svg]]
### Cloud Models
#### 3 Different Cloud Models
- Public
	- Most Common
	- Shared infrastructure (Multi-tenent)
	- Public Network
	- Network, Storage, VMS's provided by cloud provider
	- Benefits
		Easy and quick to migrate to cloud
		Control cost more effectively
		Pay for used resources
- Private
	- gain benefits of cloud in a private environment dedicated to one company
	- Private cloud can be on-prem or hosted by third party provider
	- Private cloud is also referred to as single-tenant environment
	- Main Draws:
		- Privacy
		- Regulatory concerns
- Hybrid
	- Mix of both public and private cloud 
	- Example: Application running in public cloud pulling information from data secured on-prem
