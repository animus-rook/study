## 5.2 Security Applications
### 5.2.1 Security Appliances
- Proxy Server
	- acts on behalf of user/service
	- Store and forward model 
	- Traffic Management and security
	- anonymity
	- caching services
	- Content filtering/monitoring
	- load balancing
- Jump server
	- hardened server that provides access to other hosts
	- controls access to sensitive resources
- load balancer
	- mitigation for [[Dos Denial of Service]]
	- [[failover]]
- sensor
	- packet sniffer
	- identify traffic that may have bypassed firewall
	- Data is sent to a system running an [[intrusion detection system]]
- UTM - all in one security appliance
	- managed via web interface
	- URL filtering
	- Content Inspection
	- firewall
	- IDS/IPS
### 5.2.3 Security Solution Facts
- Failure modes
	- can be configured to fail open/closed
		- open - network/host access is perserved if possible
		- closed - access is essentially blocked
- Content filter
	- All all except what you designate
	- Block all except what you designate
- Web filtering
	- Agent based focused on individual endpoints
	- Centralized multiple endpoints

## 5.3 Screened Subnets
### 5.3.1 Screened Subnets
- allows organizations to provide access to resources on their internal network
- Also known as DMZ
### 5.3.4 Screened subnet facts
- screened subnet often hosts web, email, DNS, or FTP services
- bastion/sacraficial host device that is hardened and is expected to be attacked
- Screening router - closest to internt in relation to network and uses [[(ACLs) Access controls list]] to route traffic
## 5.4 Firewalls

### 5.4.1 Firewalls
- [[WAF Web Application Firewall]] 
	- defensive wall against code injection and [[Dos Denial of Service]]
	- specific to web applications
- next generation firewall
	- deep packet inspection
	- intrusion preventions
	- works at layer 7
	- TLS inspection
- Unifies threat management
	- centralizes security controls 
	- single unified appliance
	- great for small to medium size business
- layer 4 and layer 7 firewalls
	- transport layer acts as a gatekeeper
	- Application layer (7) protocol, payload is checked 
- [[(ACLs) Access controls list]] and firewall rules
	- list of permissions on who and what is able to be accessed
	- Dest/Source IP
	- Protocol
	- Port numbers
### 5.4.2 Firewall Facts
- Firewalls monitor, filter, inspect traffic based on predefines rules or [[(ACLs) Access controls list]]
- [[hostbased firewalls]]
	- SW that checks traffic on an individual host
- [[network based firewall]]
	- inspects traffic as it flows between networks
- [[WAF Web Application Firewall]]
- [[Stateless Firewall]]
	- filters are basic packets analyzed individually
- [[Stateful Firewall]]
	- packets are analyzed holistically
