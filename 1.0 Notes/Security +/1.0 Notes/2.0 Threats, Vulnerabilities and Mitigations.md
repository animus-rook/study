### 2.1.3 General Attack Strategy

	- Depends on motivation of the threat agent
### 2.1.4 General Defense Strategy
- Fundamental security principals for defending systems
	- **Layered Defense**
		- Multiple Strategies to protect an [[Asset]]
		- deters attacks of opportunity
	- **Principal of least privilege**
		- only give users what they need to do their job
	- **Randomness**
		- personal habits should be random
		- randomize password change intervals
		- obscure information
	- **Simplicity**
		- keep it simple
		- if too complex to use, does you no good

### 2.1.7 Attack Surfaces Facts
#### Attack Surface and Threat Vectors
- Attack Surface - area that is exposed for attack
- Attack Vector - how do they actually get in
#### Vulnerable Software Vectors
- Software that contains a flaw that can exploited to gains control or crash a system
- Resolved when software vendor is made aware and patched vulnerability
#### Unsupported Systems and Applications
- systems that are no longer supported by the vendor
- safe practice to isolate away from critical systems (compensating control)
#### Client Based vs. Agent based
- scanning software that can be used to find software vulnerabilities. 
- Agentless runs without any software installed on target machine
#### Network Vectors
- software exploits can be either:
	- Remote - exploit can be conducted by sending code over network
	- Local - executed from a logged in user on machine
	- [[Unsecure network]] 
		- lacks attributes of [[CIA Triad]]
			- Confidentiality - threat actors can snoop, recover passwords etc [[eavesdropping attacks]]
			- integrity - attach unauthorized devices, with goal to intercept or modify traffic on network [[on-path attacks]]
			- Availability - Service disruptions [[Dos Denial of Service]]
## 2.2 Social Engineering
### 2.2.1 Social Engineering Overview
- [[Social Engineering]]
	- needs human interaction 
	- is hard to detect, track or deflect
	- User education is best strategy for mitigation
- [[Social Engineering]] process
	- Differnet phases
		- Research
			- Gathering infomation about victim/organization
		- Development
			- Selecting victim
			- Building Report
		- Exploit
			- Attacker taked advantage of relationship
### 2.2.2 Social Engineering Facts
- Tactics used to manipulate victims
	- Moral obligation or sense of responsability
	- Inate human trust - the wilingness to trust another human
	- threats/intimidation
	- reward - usually a big reward for a small action
	- Authority - someone would fear like "boss"
	- Social Proof - "Hey everyone has done it so far"
	- Scarcity - get it before its gone/dont miss out
	- likability - more likely to perform an action for a "friend"
	- urgency -  this needs to be done now
