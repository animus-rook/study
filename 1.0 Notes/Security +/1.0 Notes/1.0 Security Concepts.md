## 1.1 Security Introductions
### 1.1.1 The Security Landscape
- never ending arms race
- ever changing 
### 1.1.2 Security Concepts
- Assets - something that has value to individual or organization
- Threats - anything that has potential to cause loss of an asset
- Threat agent - actual person or organization that carries out threat
	- can be external or internal
	- little funding vs lota of funding
	- Organized crime
	- Nation State
	- cooperate espionage
- Vulnerability - weakness in system
- Exploit - procedure that takes advantage of vulnerability 
### 1.1.3 Security Introduction Facts
#### Security Challenges
- Sophisticated attacks - complex making then hard to stop or detect
	- uses common internet protocols 
	- behavior varies between attacks
- proliferation of attack software - malware as a service etc
- Attack scale and velocity - how quickly attacks happen and grow 
#### Security Control types
- Controls are designed to fulfill 3 main goals: [[CIA Triad]]
	Confidentiality
		- ensures unauthorized individuals are not able to gain access to sensitive org data 
		- controls include firewalls, ACL's, encryption
	- Integrity
		- ensures that no unauthorized modifications are made to data, intentionally or by accident
		- Controls include hashing
	- Availability
		- ensures that information and systems and resources are ready when users need them 
- controls are classified based on how they are implemented, the goal/function they preform

### 1.2.1 Control Categories and Types
- [[Managerial]]
	- management based techniques 
	- Policies/procedures Disaster recovery plans Buisness continuity plan
- [[Operational]]
	- Security team performs every day
- [[Technical]]
	- based around software/security appliances 
- [[Preventive]]
	- ASA Adaptive security appliance
- [[Detective]]
	- alerts team to events
	- log collects
- [[Corrective]]
	- work during and after during event
	- fixes event damage
	- endpoint detection
- [[Deterrent]]
	- security polices
	- access protected doors
	- man traps
- [[Physical]]

	- locked doors 
	- Device management
