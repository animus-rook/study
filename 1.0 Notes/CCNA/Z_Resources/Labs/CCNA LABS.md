### **Packet Tracer Lab Plan by Week**

### **Week 1: Networking Basics**

- **Lab Objective:** Create a simple LAN topology to understand basic connectivity.
- **Tasks:**
    1. Connect two PCs using a switch.
    2. Assign IP addresses and test connectivity with `ping`.
    3. Explore how a switch builds its MAC address table.

### **Week 2: Ethernet and Switching Basics**

- **Lab Objective:** Learn about MAC addressing and ARP.
- **Tasks:**
    1. Set up a topology with multiple PCs and a switch.
    2. Capture ARP requests and responses using Packet Tracer's simulation mode.

### **Weeks 3–4: VLANs and Trunking**

- **Lab Objective:** Configure VLANs, trunk ports, and Inter-VLAN Routing.
- **Tasks:**
    1. Create three VLANs on a switch.
    2. Assign switch ports to VLANs.
    3. Configure a trunk port between two switches.
    4. Use a router to enable communication between VLANs.

### **Weeks 5–6: IP Connectivity (Routing Basics)**

- **Lab Objective:** Configure static routes and single-area OSPF.
- **Tasks:**
    1. Set up three routers in a linear topology.
    2. Configure static routes to enable end-to-end connectivity.
    3. Replace static routes with OSPF and verify neighbors.

### **Week 7: Wireless Networking**

- **Lab Objective:** Configure a wireless network with basic security.
- **Tasks:**
    1. Add a wireless router and connect devices (PCs, laptops).
    2. Configure WPA2 security on the router.
    3. Test connectivity for authenticated and unauthenticated devices.

### **Week 8: Security Fundamentals**

- **Lab Objective:** Implement and test ACLs on a router.
- **Tasks:**
    1. Set up a router with two LANs.
    2. Create ACL rules to block certain traffic (e.g., block HTTP but allow ICMP).
    3. Verify the effectiveness of ACL rules using `ping` and web browsers.

### **Weeks 9–10: IP Services**

- **Lab Objective:** Configure NAT and DHCP.
- **Tasks:**
    1. Set up a topology with a router and multiple PCs.
    2. Configure NAT to translate private IPs to a public IP.
    3. Configure DHCP on the router to assign IPs automatically.

### **Week 11: Network Automation Basics**

- **Lab Objective:** Simulate network automation using basic Python scripts.
- **Tasks:**
    1. Add devices to a topology with CLI access.
    2. Write a Python script to automate device configuration (e.g., assign IPs).
    3. Simulate a REST API call in the lab.

### **Week 12: Troubleshooting Techniques**

- **Lab Objective:** Diagnose and resolve common network issues.
- **Tasks:**
    1. Set up a pre-configured "broken" topology with issues like misconfigured IPs, VLAN mismatches, or incorrect ACLs.
    2. Use troubleshooting tools (`ping`, `traceroute`, `show commands`) to resolve issues.

### **Weeks 13–14: Comprehensive Lab**

- **Lab Objective:** End-to-end network design, configuration, and troubleshooting.
- **Tasks:**
    1. Design a network with routers, switches, VLANs, and a wireless segment.
    2. Configure routing (OSPF), NAT, and ACLs.
    3. Troubleshoot connectivity issues.
