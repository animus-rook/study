# Security+ (SY0-701) Study Notes

Personal study notes for the CompTIA Security+ certification, built primarily from CertMaster (with supplementary text/video sources noted per file).

## Structure

- `domains/` — one file per exam domain, notes organized by objective
- `labs/` — one file per CertMaster (or other) hands-on lab
- `resources.md` — reference material log (books, videos, courses)
- `glossary.md` — key terms and acronyms
